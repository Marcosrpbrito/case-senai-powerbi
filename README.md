# SENAI - Análise de Contratos, Evasão e Oportunidades

## 📌 Visão Geral
Este repositório contém a resolução de um case ficticio focado no diagnóstico de cancelamentos de contratos e identificação de oportunidades de receita para o SENAI. 
O painel interativo foi desenvolvido em Power BI e cruza dados de projetos, faturamento e perfis de atendimento.

## 📊 Principais Insights do Dashboard
- **Diagnóstico de Cancelamentos:** Foram mapeados 3 cancelamentos expressivos no ciclo atual, totalizando R$ 1,5 milhão (aproximadamente 10% de todo o montante de contratos PDI).
- **Causa Raiz:** Uma análise mais profunda revelou que a maior parte da evasão (R$ 1,16 milhão) está concentrada nas indicações de um único representante, sugerindo falhas nas entregas ou no diagnóstico inicial ou no alinhamento de expectativas com esses clientes específicos.
- **Oportunidade de Crescimento:** O maior gargalo de atrasos concentra-se em empresas de grande porte.
- **Plano de Ação Estratégico:** A proposta é ajustar o escopo de novos projetos, diminuindo o tempo de entrega das Sprints através de metodologias ágeis supervisionadas. A mitigação desses atrasos abre margem para um crescimento estimado de 13% na captação e atendimento de novos contratos.
